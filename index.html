AI に任せて、
自分を拡張する

設計を詰めるのもコードを書くのも、多くは ChatGPT と Codex に任せています。 自分の仕事は、何を作るかを決めること、任せた結果を確かめること、 そして任せ方そのものを改善し続けることです。

  1. 01 目的を決める

    何を作るか、何を良しとするかを人が決める。

  2. 02 AI に任せる

    設計、実装、調査をできるだけ大きな単位で委ねる。

  3. 03 結果を検証する

    動作と根拠を確かめ、採用するものを選ぶ。

  4. 04 任せ方を改善する

    次の会話でも再現できるよう、文脈と手順を更新する。

任せる量が増えるほど、
AI が前の会話を正しく
引き継いでいるかが問題になる。

LEMP はそこから生まれました。いまは LEMP の内部版を記憶の土台にして、 LEMP 自身を開発しています。

いま作っているもの

AIに作業を任せるための道具と、そのAIが文脈を確かに引き継ぐための仕組みを作っています。

LEMP

Python / GitHub Actions / Apache-2.0

ChatGPT の GitHub 連携を使って、会話をまたいで残したい文脈を GitHub リポジトリに置く仕組みです。 ChatGPT の書き込みはまず候補として扱い、GitHub Actions の検証を通ったものだけを正本として読み込みます。

新しい会話で memory status と頼めば、ChatGPT が正本の checkpoint と検証結果を確かめて状態を報告します。 現在は公開 MVP を開発中です。

GitHubでLEMPを見る

OllaCode

Ollama / Python / Playwright optional

Ollama で動く、ローカルの AI コーディングエージェント CLI です。 ファイル編集、コマンド実行、コード検索、Python の仮想環境管理、Web 検索を、ひとつの対話の中で行えます。

ブラウザ操作が必要なときは Playwright を追加できます。
